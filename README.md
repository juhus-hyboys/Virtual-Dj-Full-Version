## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Audio and Video Mixing** — Seamlessly mix audio tracks and video content for an immersive experience.
- **CUE Points** — Locate up to 3 CUE points per track for precise control.
- **Support for Up to 99 Decks** — Mix multiple tracks at once with ease.
- **Recording Music Sessions** — Capture your live performances for later playback.
- **Integrated Mixer** — Features equalizer and gain control for professional sound adjustments.

### Advanced Features:
- **Sandbox Mode** — Mix tracks independently while another song plays, ensuring flawless transitions.
- **AutoMix** — Set sequences to automatically mix tracks at specified points.
- **Track Cleaner** — Edit tracks to remove unnecessary elements like intros or lyrics.
- **BPM Editor** — Adjust and synchronize beats for perfect timing.
- **Sample Editor** — Customize audio, video, and image samples to suit your style.
